# 08 · Plasticity

Stages 02 to 07 compare BFR with HLRT one protein, set, module or panel at a time, and none finds a
between-arm difference that passes BH. This stage asks what the two training responses share and
where they part: how far each leg moved, whether the legs moved the same proteins the same way,
whether rankings, sets and modules agree, which BFR against HLRT leads remain, and whether any
per-leg response summary tracks muscle growth.

[`01_plasticity`](01_plasticity/README.md) does all of this in one notebook. It computes response
magnitude itself (cross-fit, signature score and fry, formerly
`02_Differential_Expression/05_Response_Magnitude`) and reads the other results from stages 02 to
07.
