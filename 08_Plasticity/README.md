# 08 · Plasticity

Stages 02 to 07 compare BFR with HLRT one protein, set, module or panel at a time. This stage
compares the two training responses as wholes: magnitude, direction, coherence, the remaining
leads, and response against growth.

- [`01_plasticity`](01_plasticity/README.md): all of it in one notebook. It computes response
  magnitude itself and reads the other results from stages 02 to 07; its README gives inputs,
  outputs and results.
